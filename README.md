# C Text Formatting Practice

**C 파일 입출력과 문자열 처리를 연습한 수업용 저장소입니다.**

`main.c`는 파일 경로를 명령행 인자로 받아 줄 단위로 읽고, 공백과 빈 줄을 처리하면서 텍스트를 출력하는 코드입니다.

## 코드에서 다루는 내용

- 명령행 인자로 입력 파일 경로 받기
- `fopen`, `fgets`를 이용한 파일 읽기
- 동적으로 할당한 두 줄 버퍼를 번갈아 사용하기
- 줄 끝 공백과 빈 줄 상태에 따른 출력 제어
- 파일·메모리 할당 오류 메시지 출력

## 현재 저장소의 범위

현재 커밋에는 `main.c`가 참조하는 `Header.h`와 `Print_Line`, `Remove_Blanks_At_The_End`의 구현이 포함되어 있지 않습니다. 따라서 현재 파일만으로 독립적으로 빌드할 수 있는 완성 프로그램은 아닙니다.

`HelloGitHub`와 `comsil_5_github` 경로는 일반 소스 폴더가 아닌 Git의 다른 커밋을 가리키는 gitlink 항목입니다. 실행 방법을 추가하려면 누락된 헤더와 함수 구현, 해당 경로의 원본 구성을 먼저 확인해야 합니다.

## 구성

| 경로 | 역할 |
| --- | --- |
| `main.c` | 텍스트 파일을 읽고 줄·공백을 처리하는 진입점 |
| `ddddd.txt`, `임의.txt` | 현재 내용이 없는 텍스트 파일 |
| `HelloGitHub`, `comsil_5_github` | 다른 Git 커밋을 참조하는 항목 |

## 기술

C · 표준 파일 입출력 · 포인터 · 동적 메모리
